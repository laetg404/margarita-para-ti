
# 🌼 A Daisy for You ♡

A web-based version of the original Python Turtle animation.

This adaptation uses **HTML, CSS, and JavaScript Canvas** to recreate the original animation, making it accessible through desktop and mobile browsers.

### 🌐 Live Demo

[🌼 Watch the animation — A Daisy for You](https://laetg404.github.io/margarita-para-ti/)

---

## 💻 Run Locally

Simply open `index.html` in your browser.

No dependencies or local server are required.

---

## 🚀 Deploy with GitHub Pages

1. Create a new repository on GitHub, for example, `margarita-para-ti`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository. You can simply drag and drop the files through the GitHub website.
3. Navigate to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/(root)` folder, then click **Save**.
6. Wait for the deployment to finish. GitHub will display your website's public URL in the same section.

Every time you commit and push changes to the published branch, GitHub Pages will automatically update the website.

---

## 🎨 Customization

- **Animation messages:** Look for `setMessage(...)` and `messageLines` in `script.js`.
- **Colors and typography:** Modify the `:root` variables in `style.css`.
- **Sizes and timing:** Check the constants and animation durations inside `script.js`.
